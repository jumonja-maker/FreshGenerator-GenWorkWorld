# Отклонённый эксперимент: память высотного кэша

**Этот кэш НЕ включён в игровой JAR 0.3.3.** Прогон 43162819040 выявил девять изменённых образцов растительности на сиде 42, не воспроизведённых тремя исходными контролями. Полностью восстановлен опубликованный лесной обработчик 0.3.2. Код кэша оставлен только в `src/test`, чтобы сохранить воспроизводимый эксперимент, а не выдавать синтетические измерения за безопасное улучшение игры. Подробности и неудачные данные: [технический отчёт](technical-update-0.3.3.md).

В раннем эксперименте при первом значении выделялись массивы на 2048 ячеек. Затем начальная таблица была уменьшена до 32 ячеек с ростом при заполнении наполовину. Логический предел 1024 записи и порядок промахов были сохранены в модельных тестах. Это улучшило синтетические выделения памяти, но не оказалось достаточным доказательством сохранения результата всего мира.

Добавлены тесты начального размера, каждого расширения, signed zero, обновления существующего ключа и устаревших поколений. Локально выполнены 2 000 000 сравнений hit/miss/значения с прежней ограниченной HashMap и 250 000 синтетических обращений через независимый проверяющий объект, без расхождений. Это НЕ число вызовов внутри Minecraft.

[Измерения выделений памяти](../research/cache-allocation-check-0.3.3.json) выполнены на OpenJDK 21.0.12.1, по 2048 новых кэшей на размер. Серверные проверки используют Java 25. Например, для восьми записей получено 704 байта у HashMap и 600 у экспериментального кэша, для 128 — 11 328 и 7912. Это суммарные выделения в отдельной проверке, не постоянная занятая память, FPS или выгода опубликованного мода.

Воспроизведение эксперимента (классы не добавляются в игровой JAR):

```sh
mkdir -p build/cache-probes
javac -d build/cache-probes src/test/java/dev/freshgenerator/core/ColumnFloatCache.java src/audit/java/dev/freshgenerator/audit/ForestHeightOracle.java research/checks/CacheAllocationProbe.java research/checks/CacheTraceProbe.java
java -Xmx256m -cp build/cache-probes CacheAllocationProbe
java -Xmx256m -cp build/cache-probes CacheTraceProbe
```
