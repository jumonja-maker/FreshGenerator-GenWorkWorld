# 0.3.5-alpha.1: сокращение временных вычислений без изменения мира

Это небольшая внутренняя оптимизация защиты деревень. Цель — избежать лишних выделений памяти и повторных обращений к уже подготовленным метаданным структур. Биомы, рельеф, леса, пещеры, сами деревни и их расположение должны остаться прежними.

**Проверка лавового озера.** Раньше для каждого из 1–4 перекрываемых озером чанков заново просматривались до 289 подготовленных чанков структур. Теперь данные частей деревни собираются однократно для одной проверки озера, после чего каждый затронутый чанк по-прежнему применяет собственный фильтр частей и исходную геометрию. Общего кэша между мирами, потоками и задачами нет.

**Неактивные колонки.** Если до любой части деревни больше 24 блоков, не вычисляется высота, не создаётся объект Column. Пустой слот возвращает исходную плотность и допускает штатное вырезание. Для колонок вблизи деревни, в том числе на воде, старые расчёты сохранены.

**Защитная проверка.** Сохраняются контроль деревень относительно 0.3.3, контрольное сравнение с опубликованной 0.3.4 на тех же координатах, повторное открытие мира, контроль обычного Minecraft и аудит структур. Пакетная проверка разрешает изменение только трёх игровых классов VillageTerrainModel, VillageTerrainPlan и VillageLakeGuard; остальные классы, данные генерации и ресурсы должны быть идентичны 0.3.4.

Здесь не заявляется измеренный прирост FPS, скорости генерации или снижение пика RAM. Для этого необходимо профилирование настоящей игры с C2ME, Distant Horizons и пользовательским набором модов. Не изменяются ранее созданные чанки и сохранённые деревни. Рекомендуется резервная копия мира перед alpha-обновлением.
