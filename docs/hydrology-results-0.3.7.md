# FreshGenerator 0.3.7-alpha.1 — гидрология

## Изменения

Один самостоятельный пресет `freshgenerator:world`. Реки и озёра используют общую карту водосбора, русла и уровня воды. Вода появляется на штатной стадии заполнения чанка, включая водоёмы выше уровня моря. Озёрные чаши связаны с рассчитанными переливами; речные биомы согласованы с поверхностной водой.

Исправления интеграции сохраняют исходный климат при выборе грунта, глубокую часть пещер и правила размещения структур. Защищены источники и сухие берега от грунта деревьев, деревенские улицы — от стволов. Последняя поправка согласовала заполнение дна с существующей защитой до четырёх блоков ниже дна, устранив изолированный камень над воздухом. Ни удаления неудобных блоков после генерации, ни обхода проверки плавающего рельефа нет.

## Проверка и границы результата

Исходный код, версии Java/Minecraft/Fabric, SHA-256 игрового и исходного JAR, результаты пяти сидов, контрольные миры, происхождение отчётов и измерения времени генерации публикуются в `dist/validation-0.3.7-alpha.1.json`. Первичные наблюдения сохраняются в `dist/audits/hydrology-0.3.7-alpha.1.json.gz`.

Серверные сценарии проверяют фактические FULL-чанки: источники и лёд, поддержку дна и берегов, совпадение при обратном/параллельном запросе, повторную загрузку, обычный мир и генерацию через Distant Horizons 3.3.4. Это конечная выборка, не гарантия естественности всех рек или отсутствия дефектов на любом сиде. Шейдеры, визуальная отрисовка клиента, полный модпак и C2ME не входят в подтверждённую проверку. Геометрические проверки деревенских проходов не заменяют испытания ИИ жителей.

## Установка

Minecraft Java 26.3, Java 25+, Fabric Loader 0.20.1+, Fabric API для этой версии Minecraft. Tectonic, Terralith, Distant Horizons и другие генераторы не требуются. В `mods` должен находиться только один игровой JAR FreshGenerator; `sources.jar` не устанавливается.

Для оценки новой гидрологии создайте новый мир с пресетом FreshGenerator. На выделенном сервере до создания мира задайте `level-type=freshgenerator:world`. Уже сохранённые чанки не перестраиваются; совместимость швов со всеми прежними alpha-версиями не гарантируется. Перед обновлением существующего мира сохраните резервную копию.

## Ограничения модели

Сток рассчитывается по связанному графу до насыщения расхода, задающего максимальный размер русла; это не учёт точного объёма воды всех мировых бассейнов. Поиск озёрных чаш и переливов ограничен локальной областью. Ширина, глубина, климатическая пригодность и форма водоёма — процедурные приближения, а не результат полноценной эрозионной или сезонной симуляции. Проверки соединения воды охватывают выбранные окна, а не непрерывную съёмку каждой реки от истока до океана.
