# Единственная линия развития FreshGenerator

- Один публичный тип мира: `freshgenerator:world`, имя в интерфейсе: **FreshGenerator**.
- Улучшение гор, океанов, биомных переходов, деревьев или пещер не создаёт ещё один тип мира.
- Разные ландшафты размещаются внутри одного мира по условиям генерации, а не выбираются пользователем как отдельные режимы.
- Редкость биомов, строений и объектов учитывается автоматически; контролов редкости нет.
- Старые registry IDs — скрытые данные совместимости сохранений. Их присутствие не означает поддержку нескольких пользовательских режимов.
- Не заставлять пользователя перебирать прежние alpha-варианты ради проверки очередного исправления.
- Не обещать автоматическую переделку уже созданных чанков. Совместимость сохранений и стыки генерации проверяются отдельно от количества пунктов меню.
