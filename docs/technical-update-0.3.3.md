# Техническое обновление 0.3.3-alpha.1

Обслуживание единственного FreshGenerator, не новый вариант генерации. Контрольная версия — опубликованная 0.3.2-alpha.1 (`8bb647170ed20390fc8ae3b9e05017fbd921aa61`). Размеры биомов, рельеф, гидрология, снег, пещерные ограничения и экологическая модель не перенастраиваются.

## Изменения

Кэш высот лесного обработчика заменён с `HashMap<Long, Float>` на примитивный `ColumnFloatCache` с тем же пределом 1024 записи. В нём нет упаковки координат и высот в Long/Float и выделения узлов Map. Массивы выделяются лишь при первом настоящем образце. Логическое очищение в прежний момент заполнения реализовано сменой поколения; коллизии не вытесняют записи раньше времени. Все 64 бита координат, signed zero, отрицательные высоты, переполнение поколения и изоляция задач покрыты тестами. Кэш принадлежит одной задаче, не удерживает миры глобально.

Первоначальный четырёхканальный вариант вытеснения НЕ принят: он менял порядок промахов и вызовов нативного семплера. Текущий вариант сохраняет каждый hit/miss прежней ограниченной HashMap, что проверяется длинными последовательностями. Кэш экологических участков и порядок запросов биомов оставлены прежними.

Убрано повторное создание массива четырёх соседей для каждой лесной точки; порядок и арифметика сохранены. В обработчике пещер ограничение толщины защищаемого слоя вычисляется один раз на колонку вместо каждого блока.

Компилятор региональных биомов собирает и проверяет слой во временной карте и только затем переносит его в результат. Ошибка второго климата/маршрутизации не оставляет частично установленный первый климат.

## Проверка и результаты, которые нельзя подменять

Все 344 файла генерации, data/assets, manifest, mixin и зависимости обязаны совпасть с 0.3.2; кроме номера версии меняются только разрешённые классы. Повторная упаковка JAR и sources проверяется побайтово.

Предварительные серверные сравнения показали, что даже чистые миры неизменённой 0.3.2 могут отличаться декорациями: на сиде 42 воспроизведён один блок опавшей листвы и различие числа лесных попыток. Причина всей нативной вариативности не объявляется установленной. В прогоне 43159939077 исходные снимки давали 757/760/760 лесных попыток, кандидат — 759. Это не одинаковые счётчики и не доказанное изменение экологической формулы.

Для каждого фиксированного сида выполняются ТРИ независимых чистых контрольных мира 0.3.2, кандидат и повторное открытие кандидата. Карты климата/биомов, базовые высоты и вода остаются точными проверками. Каждый FULL-блок кандидата должен совпасть с реально наблюдавшимся состоянием на ТОЙ ЖЕ координате хотя бы одного из трёх контролей. На стабильных контрольных координатах требуется точное совпадение. Никакие виды блоков, руды, папоротники, вода или листва не исключаются глобально; третье ненаблюдавшееся состояние запрещено. Окно, в котором меняется больше 0,1% контрольных образцов, не годится для допуска технического выпуска. Все отличия и сырые состояния сохраняются. Это ограниченная проверка отсутствия новых наблюдаемых состояний, а не доказательство полной идентичности декорированного мира.

Счётчики пещер обязаны совпадать со всеми контролями. Для леса вместо требования случайного совпадения общего снимка добавлена непосредственная проверка каждого обращения к высотному кэшу в настоящем Minecraft. Только тестовый mixin ведёт параллельную прежнюю HashMap и проверяет hit/miss, момент очистки, число настоящих вызовов семплера, координаты и все биты возвращаемой высоты. Дополнительных запросов к семплеру или биомам он не делает. Ошибка любого обращения блокирует выпуск. Отсутствие подключённой проверки также блокирует выпуск. Классы и mixin этой оснастки не попадают в устанавливаемый JAR.

Общие лесные счётчики сохраняются как наблюдения: равенство первому или любому контрольному снимку указывается фактическим true/false, без произвольных допусков и без заявления детерминированности всего Minecraft. Новая проверка доказывает соблюдение прежнего протокола кэша в выполненных вызовах, а не одинаковость всех решений нативной декорации. Строгие проверки карт, воды, блоков по координатам и повторного открытия сохранения не ослаблены. Обычный Minecraft проверяется отдельно и должен остаться вне политики мода.

Структуры и опора деревень проверяются на трёх сидах с ванильными контролями. Отчёты передаются ограниченными по размеру Git-объектами внутри того же закрытого репозитория: квота Actions artifacts оказалась исчерпана. Новых веток, релизов, внешних хранилищ не создаётся, старые файлы не удаляются. SHA, номер прогона, попытка, имена файлов и контрольные суммы проверяются повторно перед публикацией. При провале обязательного задания JAR не публикуется.

Факт успешного выпуска подтверждают только `dist/validation-0.3.3-alpha.1.json` и завершённый CI, не этот документ. До публикации проверенного JAR последняя доступная сборка — 0.3.2.

## Ограничения

FPS и общий процент ускорения не измерены. Клиент, шейдеры, полный модпак, DH и C2ME не проверены. Навигация жителей не моделируется, старые предупреждения у дверей не объявляются исправленными. Созданные чанки не переделываются; перед обновлением alpha необходима резервная копия.
