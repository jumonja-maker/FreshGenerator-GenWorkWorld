# Техническое обновление 0.3.3-alpha.1

База сравнения: опубликованный 0.3.2-alpha.1, коммит `8bb647170ed20390fc8ae3b9e05017fbd921aa61`. Это обслуживание компилятора, сборки и проверок, **не очередная настройка рельефа, биомов или частоты пещер**. Выбираемый генератор остаётся один.

## Принятые изменения

`BiomeRegionCompiler` сначала проверяет и собирает региональный слой во временной карте. Ошибка второй климатической функции, конфликт сохранённого поля или неверная маршрутизация не оставляют в исходной карте наполовину установленную первую функцию. Корректные скомпилированные данные должны совпадать с 0.3.2 побайтово.

Сборка проверяет воспроизводимость обоих JAR, исключение тестовых классов из игрового мода, состав ресурсов и зависимостей. Серверные сценарии разделены по сидам и выполняются параллельными заданиями; устаревшие прогоны отменяются, а публикация проверяет, что `main` всё ещё указывает на проверенный коммит.

Передача ограниченных проверочных данных между заданиями использует Git blobs этого же приватного репозитория, без новых веток и внешних хранилищ. Это обход заполненной квоты Actions artifacts, а не отключение проверок. Проверяются коммит, прогон, попытка, пути и SHA-256 файлов. Добавлен запасной канонический адрес Maven Central для загрузки зависимостей.

## Эксперименты, исключённые из игрового мода

**Кеш высот леса.** Примитивный кеш и повторное использование соседнего массива не приняты. В прогоне `43162819040`, коммит `578b6456f2f5ce9cc665642406f0f05a2bfc5d56`, на сиде 42 в окне `(-11744,1120)` обнаружены девять отличий растительности от трёх совпавших контрольных запусков. Исходный `ForestEnvironment.java` восстановлен до blob `bcc99d4a68abdfa1f6180387bba9853a0ecd1dc1`. Экспериментальная структура данных оставлена только в тестах. Её измерения выделения памяти не являются ускорением этого выпуска.

**Кеш ограниченной толщины кровли пещер.** Перенос ограничения толщины из обработки каждого блока в обработку колонки также исключён. Прогон `43166487075`, коммит `845af54c8c7d943036e741b9d931311759fe9dc8`, остановился на сиде 1337: 391 отличие состояния блока в горном окне `(-12320,-5024)`, преимущественно скалк и жилы скалка. Три контрольных мира совпали; кандидат совпал со своим повторным открытием; суммарные решения обработчика пещер совпали. **Причина различий не доказана**: совпадение счётчиков недостаточно для объявления всей генерации одинаковой. Исследование настоящего байткода Minecraft не превратило эту находку в исправленную ошибку. `CaveCarverGuard.java` восстановлен до опубликованного blob `5f824d8412787275f8b55209a8a1dd581e5521dc`.

Исходные наблюдения не удалены:

- [Отклонённый кеш леса](../research/rejected-candidates/technical-world-fresh-42-578b645.json.gz).
- [Отклонённая оптимизация пещер](../research/rejected-candidates/technical-world-fresh-1337-845af54.json.gz).

Архивы — gzip JSON-конверты CI с исходными файлами в base64 и контрольными суммами. Новые проверки требуют совпадения **всех 28 игровых классов** и **всех 344 файлов генерации** с 0.3.2, без списка разрешённых изменений игровых классов.

## Условия выпуска

Проверяются фиксированные карты, базовая геометрия и вода, три чистых контрольных мира 0.3.2, кандидат и его повторное открытие для каждого сценария. Состояние каждого исследуемого готового блока кандидата должно встречаться в той же координате контролей; если контроли одинаковы, кандидат должен совпадать точно. Исключений для скалка, руды, растений или воды нет. Чрезмерно нестабильные контроли блокируют выпуск. Ошибки не превращаются в успех повторными попытками до удачного результата.

Отдельно проверяются настоящие структуры и связность рельефа с ванильными контролями. Наблюдатели находятся только в проверочном source set, не в игровом JAR. Предупреждения о дверях и ненайденных в ограниченном радиусе структурах сохраняются.

Наличие этого документа само по себе не означает успешный выпуск. Результат подтверждают завершённый CI и `dist/validation-0.3.3-alpha.1.json`, после чего JAR публикуется в `main`.

## Ограничения

Это технический выпуск без заявленного прироста FPS или скорости генерации. Клиент, шейдеры, полный модпак, DH и C2ME не проверены. Предыдущие визуальные ограничения и предупреждения не объявляются исправленными. Созданные чанки не перерабатываются. Перед обновлением alpha нужна резервная копия сохранений.
