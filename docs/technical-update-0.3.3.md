# Техническое обновление 0.3.3-alpha.1

Обслуживание единственного FreshGenerator, не новый вариант генерации. Контрольная версия — опубликованная 0.3.2-alpha.1 (`8bb647170ed20390fc8ae3b9e05017fbd921aa61`). Размеры биомов, рельеф, гидрология, снег, пещерные ограничения и экологическая модель не перенастраиваются.

## Принятые изменения

В обработчике штатного вырезания пещер ограничение толщины защищаемого слоя вычисляется один раз на колонку вместо каждого блока. Формула, глубина защиты, исходные разрешённые входы и передача глубоких предложений Minecraft не меняются. Реальные счётчики решений должны совпасть со всеми контрольными запусками.

Компилятор региональных биомов сначала собирает и проверяет слой во временной карте и только затем переносит его в результат. Ошибка второго климата или маршрутизации больше не оставляет частично установленный первый климат. Корректный результат компиляции обязан побайтово совпадать с 0.3.2.

Усилены проверки готового JAR, воспроизводимости сборки, отдельных ошибок компилятора, независимости тестовых наблюдателей и передачи проверочных результатов между заданиями. При провале обязательной проверки публикация блокируется.

## Отклонённый эксперимент с лесом

Примитивный кэш высот и переиспользование массива соседей НЕ включены в итоговый игровой код. Прогон [43162819040](https://github.com/jumonja-maker/FreshGenerator-GenWorkWorld/actions/runs/43162819040), коммит `578b6456f2f5ce9cc665642406f0f05a2bfc5d56`, выявил на сиде 42 девять изменённых образцов растительности в горном окне X=-11744, Z=1120. Все три независимых контрольных мира в этих образцах совпали; новые состояния кандидата не были подтверждены ими. Среди отличий — берёзовая/дубовая листва и один блок опавшей листвы. Повторное открытие кандидата было стабильным, пещерные счётчики совпали, но этого недостаточно для принятия изменения леса.

Причина всей вариативности нативной декорации не объявляется установленной. В прежних запусках расходились даже исходные миры 0.3.2. Вместо подбора удачного повтора или исключения листвы из сравнения полностью восстановлен опубликованный исходник `ForestEnvironment.java` (Git blob `bcc99d4a68abdfa1f6180387bba9853a0ecd1dc1`). В выпуске его `.class` также обязан быть побайтово исходным. Экспериментальный `ColumnFloatCache` перенесён в тестовый набор и не должен находиться в игровом JAR.

[Полная исходная неудачная выборка](../research/rejected-candidates/technical-world-fresh-42-578b645.json.gz) сохранена в репозитории. Это gzip JSON-контейнер `schema=1`, содержащий файлы с base64-содержимым и SHA-256. Его Git blob: `7b189e374033824e459bd33a3180e4a940023e13`. [Измерения выделения памяти](cache-allocation-check-0.3.3.md) относятся к отклонённому эксперименту, НЕ к улучшению устанавливаемой версии.

## Строгие условия выпуска

Все 344 файла генерации, data/assets, manifest, mixin и зависимости должны совпасть с 0.3.2. В игровых классах допускается только оговорённая правка пещерного обработчика. Новых runtime-классов нет. Повторная упаковка JAR и sources проверяется побайтово.

Для каждого фиксированного сида выполняются три независимых чистых контрольных мира 0.3.2, кандидат и повторное открытие кандидата. Карты климата/биомов, базовые высоты и вода проверяются точно. Каждый FULL-блок кандидата должен совпасть с реально наблюдавшимся состоянием на той же координате хотя бы одного из трёх контролей. На стабильных контрольных координатах требуется точное совпадение. Никакие материалы, руды, вода или листва не исключаются глобально; ненаблюдавшееся состояние запрещено. Окно с вариативностью более 0,1% контрольных образцов не допускается. Все исходные состояния сохраняются. Это ограниченная проверка, не доказательство идентичности всего бесконечного мира.

Тестовый обработчик отдельно проверяет каждый фактический вызов высотного кэша по прежнему протоколу, не добавляя запросов к высотам или биомам. Его классы и mixin не попадают в устанавливаемый JAR. Агрегатные лесные счётчики сохраняются как наблюдения, без выдуманного равенства. Карты, вода, покоординатные блоки и повторное открытие остаются обязательными проверками. Обычный Minecraft проверяется отдельно и должен остаться вне политики мода.

Структуры и опора деревень проверяются на трёх сидах с ванильными контролями. Из-за исчерпанной квоты Actions artifacts проверочные файлы передаются ограниченными Git-объектами внутри того же закрытого репозитория. Новых веток и внешних хранилищ нет. При публикации повторно проверяются исходный коммит, прогон, попытка, имена файлов и контрольные суммы. Тестовая оснастка исключена из игрового мода.

Факт успешного выпуска подтверждают только `dist/validation-0.3.3-alpha.1.json` и завершённый CI. До такой публикации последняя готовая сборка — 0.3.2.

## Ограничения

FPS и общий процент ускорения не измерены. Клиент, шейдеры, полный модпак, DH и C2ME не проверены. Навигация жителей не моделируется, прежние замечания к дверям не объявляются исправленными. Созданные чанки не переделываются; перед обновлением alpha необходима резервная копия.
