# FreshGenerator — один генератор мира

Самостоятельный мод для **Minecraft Java 26.3**, **Java 25**, **Fabric Loader 0.20.1+** и **Fabric API для 26.3**. Другие генераторы не требуются. DH Optimizer и его репозиторий не изменяются.

## Один мир, все ландшафты

В создании мира у мода **один пункт — FreshGenerator** (`freshgenerator:world`). Горы, предгорья, равнины, океаны, побережья и биомы — части одного мира, а не разные режимы. Новых вариантов генератора при технических обновлениях не добавляется.

Текущая модель содержит плавные предгорья, плечи хребтов, вершины, вариации массивов и боковые ложбины. Горы зависят от местных климатических и рельефных условий: весь мир не превращается в горы. Диапазон высот -64..319, уровень моря 63. Верхний спад рельефа находится в 288–312. Ложбины не являются физической симуляцией эрозии.

## Технический выпуск 0.2.2-alpha.1

Этот выпуск **не меняет форму мира, редкость объектов и правила размещения**. Он добавляет воспроизводимую запись ресурсов с SHA-256 каждого сгенерированного JSON и усиливает проверки генерации. При выпуске сравниваются все данные мира и байты игровых классов с 0.2.1. Тестовый анализатор блоков и структур не включается в устанавливаемый JAR.

В серверных проверках контрольные суммы теперь снимаются после предварительной загрузки соседних FULL-чанков. Это устраняет неверное сравнение раннего состояния чанка с состоянием после соседних декораций; само размещение декораций не изменено.

Отдельный аудит проверяет реальные миры FreshGenerator и ванильные контрольные миры на трёх сидах: связность природных блоков, горные участки, место появления, существующие деревни, другие структуры и нативные правила размещения. **Предупреждения о найденных объектах не скрываются и не превращаются в заявление об отсутствии ошибок.** Фактические находки и координаты: [technical-audit.json](dist/audits/technical-audit.json). Область проверки: [docs/technical-audit.md](docs/technical-audit.md).

## Скачать

После успешной проверки упаковки и серверных регрессий: [FreshGenerator-Fabric-26.3-0.2.2-alpha.1.jar](dist/FreshGenerator-Fabric-26.3-0.2.2-alpha.1.jar). Откройте файл и нажмите **Download raw file**. Нужен обычный JAR, не `sources.jar`. Отчёт выпуска: [validation-0.2.2-alpha.1.json](dist/validation-0.2.2-alpha.1.json).

Замените прежний FreshGenerator в `mods`, не устанавливайте одновременно несколько версий. Пункт создания мира остаётся **FreshGenerator**. Для выделенного сервера перед первым созданием сохранения: `level-type=freshgenerator:world`.

## Редкость — автоматически

Нет настроек редкости и ручных шансов биомов или строений. Сохраняются нативный источник биомов, structure sets, расстояния размещения, биомные ограничения и условия природных объектов. Изменение рельефа может влиять на пригодность мест; равное количество объектов на квадратный километр без статистического исследования не заявляется.

## Сохранения

Скрытые старые технические записи нужны только для открытия уже созданных сохранений. Они не входят в меню и не развиваются как дополнительные режимы. Мод не переключает генератор сохранения и не перезаписывает уже созданные чанки.

Этот технический выпуск не требует выбора нового генератора. Резервная копия перед обновлением alpha остаётся обязательной мерой предосторожности. В будущем изменение алгоритма новых чанков потребует проверки стыков; универсальная бесшовная миграция пока не реализована.

## Границы результата

Пещеры, водоносные полости, руды, структуры и основные материалы исполняются нативным конвейером Minecraft. Переходы к камню/снегу пока ограничены подходящими луговыми и продуваемыми лесными склонами. Универсальное смешивание границ биомов, гигантские деревья, новая гидрология и графический редактор ещё не реализованы.

Конечная выборка не доказывает отсутствие висящих блоков во всём мире. Проверка опоры и клеток у дверей не заменяет навигацию жителей. Клиентская картинка, весь пользовательский модпак и Distant Horizons отдельно не проверены. Никакого автоматического удаления блоков, которое могло бы повредить навесы, пещеры или строения, в мод не добавлено.
