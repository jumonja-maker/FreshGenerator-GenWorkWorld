# FreshGenerator — один генератор мира

Самостоятельный мод для **Minecraft Java 26.3**, **Java 25**, **Fabric Loader 0.20.1+** и **Fabric API для 26.3**. Другие генераторы не требуются. DH Optimizer и его репозиторий не изменяются.

## Один мир, все ландшафты

В создании мира у мода **один пункт — FreshGenerator**. Нет отдельных вариантов «сбалансированный», «горный», «альпийский», v1 или v2. Горы, предгорья, равнины, океаны, побережья и биомы являются частями одного мира. Все последующие улучшения развивают этот генератор, а не добавляют новые пункты выбора.

В выпуске 0.2.1-alpha.1 исправлена организация типов мира: единственный публичный идентификатор — `freshgenerator:world`. Он использует уже реализованную модель с плавными предгорьями, плечами хребтов, вершинами, вариациями массивов и боковыми ложбинами. Улучшения гор и ограниченные высотные переходы к камню/снегу сохранены. Локальные климатические и рельефные условия определяют расположение гор; весь мир не превращается в горы.

Это исправление выбора и организации генератора, **не новая переработка формы рельефа**. Сидированные данные текущей модели не переименованы внутри сохранений, чтобы не менять результаты генерации случайным изменением идентификаторов шумов.

## Скачать

После успешных проверок: [FreshGenerator-Fabric-26.3-0.2.1-alpha.1.jar](dist/FreshGenerator-Fabric-26.3-0.2.1-alpha.1.jar). На странице файла нажмите **Download raw file**. Для установки нужен обычный JAR, не `sources.jar`.

Замените предыдущий FreshGenerator в `mods`, не держите две версии одновременно. В стандартном создании мира выберите **FreshGenerator** — больше выбирать между вариантами не требуется. Для выделенного сервера перед первым созданием сохранения: `level-type=freshgenerator:world`.

## Редкость — автоматически

Нет настроек редкости, ручных шансов биомов или строений. Сохраняются нативный источник биомов, правила структур, расстояния размещения и условия природных объектов. Реестры биомов, structure sets и placed features не подменяются. Изменение рельефа может влиять на пригодность мест; одинаковое количество объектов на квадратный километр не обещается без измерений.

## Совместимость сохранений

Старые технические записи оставлены **только для открытия уже созданных миров**. Они не входят в список выбираемых типов мира и не являются отдельными развиваемыми режимами. Мод не переключает генератор существующего сохранения и не перезаписывает созданные чанки автоматически.

Обновление генератора само по себе не переделывает существующую территорию. Изменения алгоритма для новых чанков требуют проверки стыков и сохранения параметров мира; универсальная бесшовная миграция пока не реализована. Перед испытаниями alpha делайте резервные копии.

## Что реализовано и что ещё нет

Рельеф исполняется нативным конвейером Minecraft: пещеры, водоносные полости, руды, структуры и материалы остаются в нём. Диапазон высот пока -64..319, уровень моря 63. Верхний спад гор согласованно поднят к 288–312. Ложбины — процедурная форма, не физическая эрозия.

Переходы поверхности к камню и снегу ограничены подходящими луговыми и продуваемыми лесными склонами. Универсальное смешивание всех границ биомов, гигантские деревья, новая гидрология и графический редактор ещё не реализованы. Проверка всего модпака пользователя и Distant Horizons не выполнена.

## Проверки

Сборка включает модульные тесты, проверку единственного пункта выбора и сравнение всех прежних ресурсов с опубликованным JAR. Серверные сценарии проверяют реальную генерацию и повторное открытие через `freshgenerator:world`, а старые идентификаторы используются только в регрессионных проверках сохранений. Тестовая оснастка не входит в игровой JAR.

Фактические результаты публикуются в [validation-0.2.1-alpha.1.json](dist/validation-0.2.1-alpha.1.json) только после успешных проверок. Серверные проверки не заменяют проверку графического интерфейса в клиенте и визуальную оценку мира.
