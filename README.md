# FreshGenerator — ядро генерации, 0.1.0-alpha.1

Самостоятельный Fabric-мод для **Minecraft Java 26.3**, Java 25, Fabric Loader 0.20.1+ и Fabric API 0.165.2+26.3. Другие генераторы, Chunky и DH Optimizer **не требуются**. Репозиторий Optimize не используется и не изменяется.

## Объём первого этапа

Это начальное ядро изменения географии, не законченный редактор мира. Собственный Java-компилятор собирает версионированные графы плотности: горизонтальные масштабы материков, климатических областей и рельефа; плавное поднятие гор внутри суши; углубление океанов с защитой берегов и области грибных островов. Результат исполняется нативным конвейером Minecraft с реальным сидом мира. Это не обёртка над сторонним модом и не послойная ручная заливка чанков.

Два отдельных типа мира: **FreshGenerator: Сбалансированный** и **FreshGenerator: Высокогорье**. Обычный тип мира, Незер и Энд не заменяются. В ядре v1 сохраняются стандартный вертикальный диапазон и уровень моря 63. Гигантские деревья, новый речной гидрологический алгоритм, расширенная высота мира и графический редактор пока **не реализованы**.

## Редкость — автоматически, без настроек

Остаются штатный multi-noise выбор биомов, структуры и их structure sets, расстояния/соли размещения, биомные ограничения и обычные features. Нет ползунков редкости, пользовательских шансов структур и подмены таблиц биомов. Пещеры, водоносные полости, поверхностные материалы, руды и bearding структур остаются частью нативного конвейера.

**Сохранение правил не означает ровно такое же число структур на квадратный километр.** Изменение масштаба климата и рельефа меняет доступные подходящие места и корреляции; статистика редких биомов на больших областях и совместимость со сторонними модами требуют отдельной проверки. Автоматическая компенсация редкости и поддержка произвольного стороннего генератора биомов не заявляются.

## Установка после успешной сборки

Файл `dist/FreshGenerator-Fabric-26.3-0.1.0-alpha.1.jar`. В GitHub откройте JAR и нажмите Download raw file. Рядом — исходники и `validation-0.1.0-alpha.1.json` с фактическими результатами.

Установите JAR и Fabric API в отдельный тестовый экземпляр Prism Launcher. Создайте **новый** мир и выберите один из двух типов FreshGenerator в стандартных настройках мира. Специальной вкладки с картой ещё нет. Для выделенного сервера: `level-type=freshgenerator:balanced_v1` или `freshgenerator:highlands_v1`, только перед созданием нового сохранения.

Не меняйте тип уже существующего мира. Пока это alpha: делайте копию сохранений. Версионированные идентификаторы предназначены для сохранения воспроизводимости; после стабилизации новые алгоритмы должны получать новый идентификатор вместо изменения v1.

## Архитектура

- `src/core`: неизменяемые параметры географии, дерево выражений и собственная математическая модель рельефа. Без Minecraft API, статического RNG и изменяемого состояния мира.
- `src/tool`: адаптер формата 26.3 и компилятор ресурсов. Читает только данные из фактически разрешённого игрового JAR, рекурсивно переносит необходимые графы в пространство `freshgenerator`, согласованно меняет ссылки для terrain/climate/aquifers/spawn/materials. Сохраняет SHA-256 использованных исходных ресурсов.
- `src/main`: мод Fabric и переводы имён пресетов. Ресурсы генерируются при сборке; классы Minecraft/Fabric не включаются в JAR.
- `src/test`: проверки математики, многопоточности, форматов, ссылок и отсутствия вмешательства в редкость.
- `src/smoke`: отдельная оснастка настоящего выделенного сервера, отсутствующая в игровом JAR. Проверяет реальные FULL-чанки, два сида, оба профиля, сохранение/повторное открытие и соответствие нативных вычислений модели ядра.

Для будущего интерфейса ядро разделяет **географию** и **правила содержимого мира**. Сид обрабатывается самим Minecraft; параметры не читаются каждый тик из глобального изменяемого конфига. Переключатели редкости добавлять не нужно.

## Проверки и ограничения

`gradle clean build` компилирует с настоящими зависимостями, генерирует данные и запускает тесты. `bash scripts/world_smoke.sh` создаёт временные миры в `run/`, запускает сервер и останавливает его после проверки. Этот скрипт предназначен для разработчиков/CI, не для установки игроком.

Успешное создание небольших тестовых миров не доказывает красоту рельефа, точную статистику биомов на миллионах чанков, возможность прохождения для любого сида, совместимость с модпаком пользователя или Distant Horizons. Клиентская графика, шейдеры и визуальное отсутствие артефактов проверяются отдельно. Смотрите конкретный отчёт в `dist`, а не только зелёную отметку компиляции.

Сборка: JDK 25, Gradle 9.8.2, Fabric Loom 1.19.4. Без поддельных API-заглушек. Production JAR не содержит тестовый сервер, Unsafe или чужие классы генератора.
