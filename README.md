# FreshGenerator — один генератор мира

Самостоятельный мод для **Minecraft Java 26.3**, **Java 25**, **Fabric Loader 0.20.1+** и **Fabric API для 26.3**. Сторонние генераторы не нужны. Репозиторий DH Optimizer не изменяется.

В создании мира у мода **один пункт — FreshGenerator** (`freshgenerator:world`). Горы, равнины, океаны, предгорья и биомы — части одного мира. Обновления не добавляют новые пользовательские варианты генерации.

## Исправление рельефа 0.2.3-alpha.1

Изменено формирование внешней поверхности активного генератора. Вместо неограниченных выступов исходного объёмного шума используется непрерывная высотная оболочка с ограниченными деталями. Высокие склоны получают связный приповерхностный слой; верхняя высота ограничивается плавно, а не плоским обрезанием. Предварительная оценка поверхности для материалов и водоносных полостей согласована с новой оболочкой.

Это изменение генерации, **не удаление блоков после загрузки мира**. Нативное приспособление грунта к структурам сохранено вне ограничения поверхности. Нативные пещеры сохранены глубже под оболочкой, но высокогорные приповерхностные входы, подрезы и навесы теперь ограничены сильнее. Не заявляется, что все прежние пещерные формы остались идентичными.

Диапазон измерения остаётся -64..319, уровень моря — 63. Все настройки редкости отсутствуют: штатные определения биомов, структур, structure sets и placed features не заменяются. Изменение пригодной территории может менять фактическое распределение структур; одинаковая плотность объектов на площади не гарантируется.

## Подтверждённые результаты

Сборка прошла 83 модульных теста и 15 запусков настоящего Minecraft/Fabric сервера, включая создание и повторное открытие единственного мира FreshGenerator, регрессии прежних сохранений и свежий аудит на сидах 42, 1337, -20261111 с ванильными контролями. Аудит относится к исправленному коду, а не переиспользован из прежней сборки.

В проверенных FULL-областях FreshGenerator не обнаружено полностью изолированных надземных природных компонентов по шестисвязному анализу: 0 на каждом из трёх сидов. Пограничные неопределённые компоненты и ограничения классификации сохранены в отчёте. Это конечная выборка, не доказательство отсутствия любого висящего блока во всём мире.

Определения 52 штатных структур и 21 набора размещения совпали с игровыми данными и контрольными мирами. Проверено по две деревни и три другие структуры на сид. Подвешенных целиком частей деревень по используемому геометрическому критерию не найдено. Остались четыре предупреждения о локальном пространстве возле дверей; навигация жителей не моделировалась. До и после изменения могут выбираться разные ближайшие деревни, поэтому число предупреждений не является строго парным сравнением одинаковых домов.

Дополнительная проверка нативного графа проверила по 160 колонок и 15 360 значений монотонной внешней плотности на сид, опорный приповерхностный слой и сохранение влияния глубоких пещер. Тестовые классы не включены в игровой JAR.

## Важно для существующих миров

**Уже созданные чанки не перегенерируются и не очищаются автоматически.** Исправление применяется при создании новых чанков текущего генератора; сохраняется тот же пункт FreshGenerator и те же внутренние идентификаторы. На стыке старой и новой территории возможны различия рельефа. Универсальная бесшовная миграция не реализована. Перед обновлением сделайте резервную копию; не удаляйте игровые чанки без отдельной проверки сохранения построек.

Для чистой оценки исправления используйте новое тестовое сохранение с тем же единственным типом FreshGenerator. Скрытые записи прежних выпусков не являются дополнительными режимами меню.

## Границы результата

Точные места со скриншотов пользователя не воспроизведены: их сид и координаты не предоставлены. Клиентская визуальная оценка, весь модпак и Distant Horizons отдельно не проверены. Не заявляется устранение всех резких уступов во всём мире или идеальная доступность каждого дома.

Универсальное смешивание всех границ биомов, гигантские деревья, физическая эрозия, новая гидрология и графический редактор пока не реализованы. Выпуск остаётся alpha.
